Description

Villa Benicassim is a spacious and comfortable accommodation that has a private parking lot with 2 spaces.

It has 3 bedrooms, accessible by an external staircase, in which we can find four single beds and a double bed. It also has two bathrooms, an equipped kitchen, a living room, a television, garden, swimming pool, balcony and a terrace.
